# Click-through tests

These open the suite from its files (`file://`) in a headless Chromium browser (the engine inside Edge) and click through it, at Harry's screen sizes:

- the laptop in a maximised Edge window (1707 × 930, pixel ratio 1.5) and in full screen (1707 × 1067)
- the TV (1920 × 1080, pixel ratio 1)
- a smaller window (1280 × 720)

They're for the people building the suite. Harry doesn't need to run them; his checks are the tickbox lists in each pull request, and `tests/rules.html`, which he can double-click.

`tests/static-check.js` needs no browser: it checks that every script, style and Bastion picture a page or tool names is there and that nothing points at the war game that was deleted on 22 October 2026. Run it with `node tests/static-check.js`.

## Running them

Needs Node.js and Playwright with its Chromium browser.

```
node tests/e2e/phase1.test.js
```

If Playwright is installed globally, point Node at it, e.g. `NODE_PATH=$(npm root -g) node tests/e2e/phase1.test.js`. Screenshots go to the folder in `TSI_SHOTS` (or the system temp folder).

## What the tests use

- `tests/harness.html` is a copy of `index.html` that adds a pretend **Demo tool** (`tests/fixtures/`). It tests saving, Export and Import, shutting a tool down, player windows and error handling before any real tool exists. It has its own saved data (the browser database `tsi.test`, set by `data-tsi-space="test"` on its `<html>`) and its own backups, so nothing it does can reach the real suite's saves or backups, and neither will load the other's backup files. The top bar says "Test page".
- Buttons ignore a second click within 350 ms (double-click protection), so the helpers pause briefly before clicking the same button again.
- Don't use Playwright's request interception with player windows: it stops their stylesheets loading.
- `beasthandler.test.js`: the Beast Handler companion (read-only since 22 October 2026). The Bastion is built in one window (a Beast Pen with Elara's wyvern and a second beast, a griffin, one that has no handler and one that is not acclimatised yet, and one DM-only Chronicle note) and the companion is opened in another. It checks the Home directory and "Viewing as", other players' beasts as plain lines, a Bond 0 beast as a line that says "Not acclimatised yet" and shows nothing else, the Bond page (the page a beast opens on: three tabs, the harmless greeting), a read-only Profile, the read-only Chronicle, that there are no Orders and nothing to type, a phone-sized screen, the laptop and the TV, reduced motion, and that the Bastion itself never changed.
- `beasthandler-bond.test.js`: the bottom bar and the Bond page (22 October 2026): the three tabs in order (Profile, Bond, Chronicle) with Bond the landing page and no Orders tab, the bond pills following the Bastion's bond, and a new snapshot arriving while the subspecies roll or the personality dice are playing not cutting them (the same elements stay on screen, they land, and only then is the screen redrawn).
