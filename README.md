# The Scarlett Isles: D&D Tool Suite

The ultimate suite of browser-based tools and applications to help Dungeon Masters and players alike run their D&D 5e campaigns in the world of The Scarlett Isles.

## Opening it

Download or copy the whole folder, then **double-click `index.html`**. It opens in your browser (Edge at the table). It needs no internet and nothing to install. The only exception is the Knightly Treasures shop link, which opens the shop's website.

Your work is saved in the browser on that computer. Use **Back up everything** on the home screen now and then, and keep the file somewhere safe. Clearing the browser's history and site data would also clear the suite's saves.

## What's in the folder

- `index.html`: the suite. `player.html` is the players' window, which the tools open themselves.
- `shared/`: the look (colours, fonts, buttons) and the parts every tool shares.
- `tools/`: one folder per tool, added as each is rebuilt.
- `tests/rules.html`: double-click to run the rules tests.
- `docs/`: the plan, progress notes, known issues and asset list.
- `licences/`: the licences for the bundled fonts and libraries.
